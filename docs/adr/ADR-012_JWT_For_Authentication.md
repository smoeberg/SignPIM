# ADR-012: JWT for Authentication (Fase 2)

**Status:** Proposed
**Date:** 2026-07-25

## Context
Basic auth er tilstrækkelig til Sprint 0-9, men ikke til enterprise.

## Decision
I fase 2 implementeres JWT (JSON Web Tokens) for authentication.

## Consequences
- Sikrere authentication
- Stateless sessions
- Bedre integration med SSO
